# AI Document Analyzer (RAG System)

An enterprise-grade Retrieval-Augmented Generation (RAG) system designed to extract, process, and interact with complex PDF documents. 

This project demonstrates the integration of Generative AI with vector databases to create a contextual document reading assistant suitable for corporate environments, analyzing contracts, technical manuals, and reports.

## Project Structure

This repository is structured as a monorepo containing both the backend and frontend environments:

* `/backend`: Python-based REST API utilizing FastAPI for document processing, embedding generation, and LLM orchestration.
* `/frontend`: React application providing a user interface for document upload and chat interaction.

## Core Technologies

* **Backend:** Python, FastAPI
* **AI Orchestration:** LangChain, Google Gemini API
* **Vector Database:** ChromaDB
* **Frontend:** React
